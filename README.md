# 全球首款专业级小六壬 AI 占卜产品 · 全球发布战略汇报

一份单文件 HTML 商业汇报 PPT（22 页）。

## 使用方式

1. 直接双击打开 `index.html`，或部署到任意静态托管（GitHub Pages / Vercel / Netlify）。
2. 浏览：滚轮 / `↑↓` / `←→` / `PageUp / PageDown` / `Space` 切换页面。
3. 导出 PDF：浏览器（建议 Chrome）`Ctrl/Cmd + P` → 目标"另存为 PDF" → 纸张选择"横向 / Landscape"、缩放 100%、勾选"背景图形"即可导出整套幻灯片。

## 技术栈

- Tailwind CSS（CDN）
- Chart.js 4.x（CDN，所有数据图表）
- Google Fonts：Noto Serif SC / Noto Sans SC / Cinzel
- 纯静态，无需构建。

## 设计基调

- 配色：墨黑 `#0b0712` / 深紫 `#3a1d6e` / 金 `#d4af37`
- 元素：太极、八卦同心圆作为东方神秘视觉锚点
- 数据：所有关键数字均以图表呈现（柱状 / 雷达 / 气泡 / 折线 / 漏斗）
- 排版：标题衬线（Noto Serif SC）+ 正文无衬线（Noto Sans SC）
